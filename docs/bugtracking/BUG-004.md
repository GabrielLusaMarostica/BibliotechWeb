# BUG-004 – Texto maior que a coluna do banco vira erro 500

- **Rótulos:** `bug`, `severidade: alta`
- **Encontrado em:** 2026-10-23 · **Origem:** Teste exploratório
- **Status:** corrigido e fechado

## Descrição
Nome com 400 caracteres estoura o `VARCHAR(120)`; a API respondia 500 "Erro ao acessar o banco de dados" em vez de explicar o problema. O front-end também não limitava o tamanho.

## Passos para reproduzir
1. `POST /api/alunos` com `nome` de 400 letras.

## Resultado esperado
HTTP 400: "O campo 'nome' deve ter no máximo 120 caracteres."

## Resultado obtido
HTTP 500 "Erro ao acessar o banco de dados."

## Correção
`Validacao.obrigatorio/opcional` ganharam limite de tamanho, aplicado em Aluno, Funcionario, Livro e Usuario com os mesmos tamanhos do `schema.sql`; regras `maximo(n)` no JavaScript.
