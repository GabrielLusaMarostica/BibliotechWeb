# BUG-003 – Erro 500 em todas as rotas com `{id}` fora do Maven

- **Rótulos:** `bug`, `severidade: baixa`
- **Encontrado em:** 2026-10-23 · **Origem:** Teste automatizado (JUnit)
- **Status:** corrigido e fechado

## Descrição
`@PathVariable int id` sem nome falha com "Name for argument of type [int] not specified" quando o código é compilado sem a opção `-parameters` (por exemplo, em outra IDE ou em outro build).

## Passos para reproduzir
1. Compilar sem `-parameters`.
2. Chamar `GET /api/alunos/1`.

## Resultado esperado
HTTP 200 com o aluno.

## Resultado obtido
HTTP 500 (exceção de argumento).

## Correção
Todos os `@PathVariable` e `@RequestParam` passaram a declarar o nome explicitamente.

## Teste de regressão
`ApiRestTest` (18 testes, usa todas as rotas com id).
