# BUG-005 – Id não numérico na URL devolve página HTML

- **Rótulos:** `bug`, `severidade: média`
- **Encontrado em:** 2026-10-23 · **Origem:** Teste exploratório
- **Status:** corrigido e fechado

## Descrição
`GET /api/alunos/abc` devolvia a página HTML de erro do servidor, que o front-end não sabe ler.

## Passos para reproduzir
1. `GET /api/alunos/abc` com token válido.

## Resultado esperado
HTTP 400 em JSON: "Valor inválido para o parâmetro 'id'."

## Resultado obtido
HTTP 400 com corpo HTML.

## Correção
`ControladorExcecoes` ganhou o tratamento de `TypeMismatchException`.

## Teste de regressão
`ApiRestTest.idNaoNumericoDa400EmJson`, caso CT-X02.
